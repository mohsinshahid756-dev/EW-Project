1. Project Overview
The goal was to create an automated security system that monitors a specific area for intruders. The system features a visual "Safe" indicator, a multi-stage rhythmic alarm, a persistent intruder counter, and real-time event logging.

2. Components Used
Microcontroller: Arduino Uno

Sensor: IR Obstacle Avoidance Sensor (Active IR)

Visual Indicators: 1x Yellow LED (Status), 1x Red LED (Alarm)

Auditory Alert: Active Buzzer (Pulse-modulated via software)

Interface: Serial Monitor (Real-time Clock & Intruder Log)

Passive Components: 220-ohm Resistors, Breadboard, Jumper Wires

3. The Challenges & Solutions (The "Engineering Journey")
Every project has hurdles; these were the most significant ones we overcame:

The Hardware Pivot (PIR vs. IR):
Initially, we used a PIR (Passive Infrared) sensor. However, due to "floating" pins and a lack of soldering on the jump pads, the sensor triggered constantly without motion. We pivoted to an Active IR sensor, which provided much cleaner digital signals and better reliability for a "tripwire" setup.

Active Buzzer Limitations:
Unlike passive buzzers, our active buzzer couldn't change pitch. We solved this by using Rhythmic Modulation, creating a "heartbeat" beat and a frantic "warning" strobe through timing logic rather than frequency shifts.

No Hardware Clock:
Without an RTC module, the Arduino cannot "know" the actual time. We implemented a Serial-Sync feature, where the user inputs the current time at boot-up, allowing the software to track real-world hours, minutes, and seconds.
/*
 * ULTIMATE SECURITY SYSTEM v4.0
 * Features: Real-Time Logging, Intruder Counter, Warning Siren
 */

const int irPin = 2;
const int yellowLed = 7;
const int redLed = 5;
const int buzzer = 6;

int intruderCount = 0;
bool isTriggered = false; 
unsigned long detectionStartTime = 0; 
long startTimeInSeconds = 0; 

void setup() {
  Serial.begin(9600);
  pinMode(irPin, INPUT);
  pinMode(yellowLed, OUTPUT);
  pinMode(redLed, OUTPUT);
  pinMode(buzzer, OUTPUT);

  Serial.println("--- SYSTEM INITIALIZING ---");
  Serial.println("Please set current time in Serial Monitor (HHMM)");
  
  while (Serial.available() == 0) {
    digitalWrite(yellowLed, HIGH); delay(100); digitalWrite(yellowLed, LOW); delay(100);
  }
  
  int inputTime = Serial.parseInt();
  startTimeInSeconds = ((inputTime / 100) * 3600L) + ((inputTime % 100) * 60L);
  Serial.println("TIME SYNCED. MONITORING ARMED.");
}

void loop() {
  int sensorState = digitalRead(irPin);
  long curSecs = startTimeInSeconds + (millis() / 1000);
  int h = (curSecs / 3600) % 24;
  int m = (curSecs / 60) % 60;
  int s = curSecs % 60;

  if (sensorState == LOW) {
    if (!isTriggered) {
      intruderCount++;
      isTriggered = true; 
      detectionStartTime = millis(); 
      Serial.print("[");
      if(h<10) Serial.print("0"); Serial.print(h); Serial.print(":");
      if(m<10) Serial.print("0"); Serial.print(m); Serial.print(":");
      if(s<10) Serial.print("0"); Serial.print(s);
      Serial.print("] ALERT #"); Serial.println(intruderCount);
    }

    digitalWrite(yellowLed, LOW); 
    unsigned long duration = millis() - detectionStartTime;
    
    if (duration > 5000) { 
      // Warning Stage
      digitalWrite(redLed, HIGH); digitalWrite(buzzer, HIGH); delay(100);
      digitalWrite(redLed, LOW); digitalWrite(buzzer, LOW); delay(100);
    } else {
      // Normal Alert Stage
      digitalWrite(redLed, HIGH); digitalWrite(buzzer, HIGH); delay(70);
      digitalWrite(redLed, LOW); digitalWrite(buzzer, LOW); delay(70);
      digitalWrite(redLed, HIGH); digitalWrite(buzzer, HIGH); delay(70);
      digitalWrite(redLed, LOW); digitalWrite(buzzer, LOW); delay(500); 
    }
  } else {
    digitalWrite(yellowLed, HIGH);
    digitalWrite(redLed, LOW);
    digitalWrite(buzzer, LOW);
    isTriggered = false; 
  }
}

5. Key Lessons Learned
Debouncing: We learned that sensors can be "noisy." Using boolean flags (isTriggered) is essential to prevent a single event from being counted hundreds of times.

Active Low vs. Active High: We discovered that IR sensors often work on "Inverse Logic" (LOW = Detected), which is a common standard in industrial electronics.

Software over Hardware: We learned that when hardware is missing (like a button or a clock module), smart software coding can often fill the gap and provide the same functionality.
